# 맵 에디터에서 맞춘 머티리얼을 Client로 연결하기

셰이더 기능이 바뀔 때마다 맵 에디터도 수정해야 했습니다. 반대로 맵에 새 기능이나 텍스처가 필요할 때도 양쪽을 맞춰야 했고, 전체 셰이더를 파악하며 머티리얼을 설정하기 어려웠습니다.

맵·셰이더 담당자가 전달한 문제점과 인수인계 내용을 바탕으로 AI를 활용해 두 코드의 구성을 분석했습니다. 셰이더의 머티리얼 기능을 에디터에서 설정하고 확인하도록 연결했습니다. 커스텀 설정은 JSON으로 분리하고 Client가 이를 읽도록 구성했습니다.

`에디터의 설정·미리보기 → JSON 저장 → Client 로더·어댑터 → 게임 적용`

이 흐름은 설명용 요약입니다. 이후 추가되는 모든 셰이더 기능이 자동 반영된다는 의미는 아닙니다. 셰이더 자체와 팀 맵 에디터 전체는 이 저장소의 공개 범위에 포함하지 않았습니다.

코드는 [맵 통합 폴더](../code/04-map-integration)에 있습니다. MapAdapter·MapLoader는 본인 것으로 기록된 함수만 발췌했습니다. 공동 편집된 SceneContext와 셰이더 코드는 제외했으므로 이 공개본만으로 에디터 전체의 구현을 확인할 수는 없습니다. 파일별 범위는 [manifest](../source-manifest.json)에서 확인할 수 있습니다.

작업 과정은 2026-10-19 본인 회고, 구현 범위는 기존 코드와 Git 이력을 바탕으로 정리했습니다. AI 도구명·요청 원문·답변별 수정 내역은 아직 확보하지 않았습니다. AI가 작성한 코드의 양이나 시간 절감 수치는 제시하지 않습니다. 같은 오브젝트의 Editor 설정·JSON 필드·Client 결과 화면은 추가 촬영할 자료입니다.
